## How to Use

**Find a job:**
- Browse the lists above or use the web app
- Filter by company, role, or location
- Click apply links to submit

**Add a job:**
Submit via [issue](https://github.com/aprameyak/2027-tech-jobs/issues/new/choose) with:
- Company name
- Position title
- Location
- Application link

See [CONTRIBUTING.md](./CONTRIBUTING.md) for details.

## Salary Ranges

**Software Engineering (New Grad)**
- FAANG+: $130k–$240k/year
- Quant: $180k–$400k/year
- Fortune 500: $85k–$130k/year

**Internships**
- Standard: $50–$75/hour
- Top tier: $60–$80/hour
- Quant: $70–$90/hour

## Getting Started

- Apply as soon as listings post
- Customize your resume for each role
- Use referrals when possible
- Practice interviews early
- Check visa sponsorship before applying
